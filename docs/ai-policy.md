# AI Policy

Terrain HiGAN uses AI tools as part of its development and maintenance workflow.
The project's position is to be open about that use and the extent of AI's role
in different parts of the codebase. AI assistance has included refactoring,
debugging, documentation, and code generation.

## History and scope

Much of this project predates AI development tooling. AI was later used to help
port aspects of the project from TensorFlow to PyTorch and to maintain and extend
the codebase.

The training code and model code are mostly handcrafted, with AI used for
maintenance. Their origins differ from those of the web demo, which is
effectively entirely built and maintained with AI. The project author's
experience with WebGL, WASM, and JavaScript is very limited, and AI has played a
central role in implementing the browser experience.

## Tools used

Various AI models and tools have been used throughout the project. Codex is the
primary tool; Claude and a number of open source models have also been used.
